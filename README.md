# Minha Rotina

Um app simples e pessoal para ajudar mães ocupadas (trabalho, casa, filhos, catequese,
Instagram) a organizar a rotina da semana, tarefas recorrentes e a limpeza mensal da casa.

## Como usar

Abra `index.html` no navegador. Não precisa instalar nada nem ter internet — tudo
funciona localmente e os dados ficam salvos no próprio navegador (`localStorage`).

Para hospedar online (ex: GitHub Pages), basta publicar os arquivos `index.html`,
`styles.css` e `app.js` como estão.

## Funcionalidades

- **Hoje**: veja os compromissos do dia e as tarefas pendentes, com um campo de
  adicionar rápido.
- **Semana**: monte a agenda semanal da família — dias de afterschool, catequese,
  trabalho, Instagram etc.
- **Tarefas**: lista de tarefas com categoria (casa, trabalho, filhos, catequese,
  Instagram, pessoal) e repetição (uma vez, diária, semanal ou mensal). Tarefas
  recorrentes voltam a ficar pendentes automaticamente quando o período vira.
- **Limpeza**: checklist de limpeza mensal da casa com barra de progresso, que
  reseta sozinha todo mês.
- **Família**: cadastre os filhos, seus dias de afterschool e atividades.

## Backup

Em Configurações (ícone ⚙️ no topo) é possível exportar um backup em `.json` e
importar depois, além de zerar todos os dados se quiser recomeçar.
